# Snowfall ❄️🎄

A Christmas winter theme for the Claude desktop and mobile apps. Snow falls over a snowy landscape: pine trees with twinkling lights and a star, snow-capped mountains, a cabin with warm windows, reindeer on the hills and a reindeer sleigh flying past the moon.

**The snow follows your context window:** the fuller the context, the heavier the snowfall (from a few flakes up to 260), and the snowdrift at the bottom grows too. After a compaction it drops back to a light flurry.

- Light mode: a snowy afternoon. Dark mode: a starry Christmas night.
- All motion is slow, with no flashing; with Reduce Motion on, the scene rests still.
- The theme draws in the desktop and mobile apps; the terminal shows no themes.

## Install

At the prompt of a terminal session:

```
/plugin install snowfall --marketplace sotcsa/claude-snowfall
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```bash
claude plugin install snowfall --marketplace sotcsa/claude-snowfall
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `sotcsa/claude-snowfall`, then **Add plugin**.
